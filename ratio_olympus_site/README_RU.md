# ОЛИМП — Доктор Рацио

Проект подготовлен для бесплатной публикации на **Cloudflare Pages**.

## Что есть
- Чат с Рацио через Groq (серверный вызов, ключ не попадает в браузер).
- Профиль в стиле социальной сети.
- Система доверия: подарки повышают дружеское доверие.
- Валюта за мини-игру «Полёт Икара» (3 монеты за каждые 5 колонн).
- Лавка подарков.
- Локальные воспоминания и сохранение прогресса в браузере.

## Публикация бесплатно на Cloudflare Pages
1. Создай аккаунт на https://dash.cloudflare.com/ и открой **Workers & Pages → Create → Pages → Upload assets**.
2. Проще всего: распакуй ZIP, загрузи содержимое папки `ratio_olympus_site` как проект Pages. Для использования Functions удобнее подключить репозиторий GitHub: создай репозиторий и загрузи в него `index.html` и папку `functions`.
3. В Cloudflare Pages выбери **Connect to Git** и подключи репозиторий. Framework preset: **None**; Build command оставь пустым; Build output directory: `/` (корень проекта).
4. После создания проекта открой **Settings → Variables and Secrets → Add**. Добавь секрет с именем `GROQ_API_KEY` и значением своего НОВОГО ключа Groq. Сохрани и сделай redeploy.
5. Открой выданный адрес `*.pages.dev`. Проверь чат.

## Важно
- Отзови ключ, который ранее случайно отправил в чат. Используй новый ключ и добавляй его только как Secret в Cloudflare.
- Не вставляй ключ в `index.html`, GitHub или публичные сообщения.
- Бесплатные лимиты Cloudflare и Groq могут меняться.
- Отношения/монеты/переписка сейчас сохраняются локально в браузере конкретного устройства. Для общего аккаунта между устройствами потребуется база данных и авторизация.
- Это дружеская система доверия и привязанности, без романтического отыгрыша.
